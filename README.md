# 被撕掉的那幾頁

《鴨子探索：是誰？》的遊玩重建筆記：作品介紹、故事還原、完整攻略。

原作是陳怡珊在 Larch 平台做的視覺小說，2026-09-08 上市集，第二屆創作者挑戰參賽作品。
主線 94 張卡、113 條連線、20 個變數、四個結局；第二章是一本被撕掉的日記，四十一則。

作品頁：<https://larch.ink/play/market/b1ce07d9-39f7-429b-8466-9ab6b3778c38>

## 這個 repo 在做什麼

一頁 GitHub Pages，`index.html`，沒有 build step、沒有相依套件。八節：

1. 這是一款什麼樣的作品
2. 你需要先認得的幾個人
3. 第二章：泥巴人的小日記（四十一則原文，旁邊加註記）
4. 被撕掉的那幾頁（用主線的證據把 8/30 之後補回去）
5. 四個結局怎麼拿（完整攻略）
6. 心幣經濟學：作者埋的陷阱
7. 一份閱讀式的感想
8. 資料來源與授權

目標是讓沒玩過、也不打算玩的人，把整個故事看懂。

## 資料怎麼來的

```
python3 tools/fetch_snapshot.py                  # 印出全部卡片、選項、變數與連線條件
python3 tools/fetch_snapshot.py --json duck.json # 另外存一份原始快照
```

讀的是 Larch 的公開市集端點 `GET /api/marketplace/<gameId>?play=1`，不需要登入，
拿到的是作者自己按下發佈的快照，不會動到作者的專案。

快照是作者的著作，`.gitignore` 已經把它擋掉，本 repo 不收錄，也請不要重新散布。

## 定位

這是一份收藏，不是攻略站。

- **最上面第一句就是分享的立場**：好作品應該更容易被看見，這一頁存在的目的只有一個，
  讓更多人去玩它。去玩的按鈕是整頁第二個元素，防雷提醒降到它下面。
- **視覺參考作者自己的「粉派鴨鴨」風格**：白底、粉紅線條、鼠尾草綠、手寫楷體，
  取自她三部作品的封面實際取色（#FFCBDD／#FAE1E9／#829367／#57634E）。
  首屏是她封面的粉紅天空，白紙從中間被撕開。
- **十六處連結指回 Larch**：作者個人頁、作品頁、第二屆創作者挑戰賽事頁，
  以及她另外兩部《鴨子日常：懷舊篇》《鴨鴨旅遊大亨》。

頁面不使用作者的任何圖檔，風格用 CSS 表現，不去打她的 R2 流量。

2026-09-18 公開。作者自己的完整攻略預告在 9/20 放市集留言區。

# 被撕掉的那幾頁

《鴨子探索：是誰？》的遊玩重建筆記：作品介紹、故事還原、完整攻略。

原作是陳怡珊在 Larch 平台做的視覺小說，2026-09-08 上市集，第二屆創作者挑戰參賽作品。
主線 94 張卡、113 條連線、20 個變數、四個結局；第二章是一本被撕掉的日記，四十一則。

作品頁：<https://larch.ink/play/market/b1ce07d9-39f7-429b-8466-9ab6b3778c38>

## 這個 repo 在做什麼

一頁 GitHub Pages，`index.html`，沒有 build step、沒有相依套件。八節：

1. 這是一款什麼樣的作品
2. 你需要先認得的幾個人
3. 第二章：泥巴人的小日記（四十一則原文，旁邊加註記）
4. 被撕掉的那幾頁（用主線的證據把 8/30 之後補回去）
5. 四個結局怎麼拿（完整攻略）
6. 心幣經濟學：作者埋的陷阱
7. 一份閱讀式的感想
8. 資料來源與授權

目標是讓沒玩過、也不打算玩的人，把整個故事看懂。

## 資料怎麼來的

```
python3 tools/fetch_snapshot.py                  # 印出全部卡片、選項、變數與連線條件
python3 tools/fetch_snapshot.py --json duck.json # 另外存一份原始快照
```

讀的是 Larch 的公開市集端點 `GET /api/marketplace/<gameId>?play=1`，不需要登入，
拿到的是作者自己按下發佈的快照，不會動到作者的專案。

快照是作者的著作，`.gitignore` 已經把它擋掉，本 repo 不收錄，也請不要重新散布。

## 定位

這是一份收藏，不是攻略站。

- **最上面第一句就是分享的立場**：好作品應該更容易被看見，這一頁存在的目的只有一個，
  讓更多人去玩它。去玩的按鈕是整頁第二個元素，防雷提醒降到它下面。
- **視覺參考作者自己的「粉派鴨鴨」風格**：白底、粉紅線條、鼠尾草綠、手寫楷體，
  取自她三部作品的封面實際取色（#FFCBDD／#FAE1E9／#829367／#57634E）。
  首屏是她封面的粉紅天空，白紙從中間被撕開。
- **十六處連結指回 Larch**：作者個人頁、作品頁、第二屆創作者挑戰賽事頁，
  以及她另外兩部《鴨子日常：懷舊篇》《鴨鴨旅遊大亨》。

頁面不引用作者的任何圖檔，風格用 CSS 表現。
（作品的圖存在 Larch 平台自己的 R2 上，不是作者的圖床——她跟其他作者的封面在同一個 bucket 與路徑前綴。）

**這一頁刻意不掛贊助 footer。** 在別人的作品頁上跟讀者要咖啡，位置不對。
頁尾只留一行署名與 repo 連結。拿掉 snippet 之後整頁零 JavaScript。

頁面末尾帶一條到 [patient-9-guide](https://yazelin.github.io/patient-9-guide/)，
QIYUN《第九號病人》的讀本站，同一屆創作者挑戰的作品，兩邊互相連。

2026-09-18 公開。作者自己的完整攻略預告在 9/20 放市集留言區。

## 訂正紀錄

**2026-09-18**：作者陳怡珊看過這一頁，說有些地方寫得不夠精確。逐條對回她的公開快照
（release 23）之後改掉八處，四處會影響通關：

1. **泥巴人的相框有隱形門檻**——`inventoryUseConditionVariable` 是 `NibberAffection`、
   值 `3`。好感度沒到 3，在市政府按不下去。原本把第二趟泥巴路寫成「順便拿線索」。
2. **回家要分三趟**——可點的 actor 只掛在進門第一張卡，點了鴨子哥哥就直接進選項、
   結束後只剩「出門」，那一趟搜不了家。原本寫得像同一趟做得完。
3. **棒球不能拿來應付阿壹**——它的 `inventoryStoryNodeId` 指向「神奇歌唱棒球」，
   使用條件正是 `meet_1`，用下去會唱歌、偷一根螃蟹腳，然後把你送回家。
4. **鴨鴨圍巾沒有 `inventoryName`**——村落搶劫那張的判定是「交出去的東西名字不是空的」，
   所以交圍巾很可能被判成沒給。原本寫「給棒球或圍巾」。
5. 心幣總量改成與市長台詞「三個以上」並陳，不再單方面斷言只有三枚。
6. 「阿壹就是村民1」標成推論——他自我介紹只說叫阿壹，遊戲沒有直接標。
7. 「後山就是泥巴路的土堆」標成推論——遊戲沒有把兩者接起來。
8. 拿掉「一輪大概半小時」，全文沒有任何時間敘述，那是我自己編的。

**2026-09-18（第二輪）**：把作者的 23 則更新記錄整段讀完之後，再改四處。
上一輪我拿了那份資料卻沒用，結果把她刻意設計的東西寫成毛邊。

1. **棒球講反了。**上一輪我寫「棒球不要在阿壹面前用」。實際上那正是它的用途：
   道具說明是「遇到無法拒絕的情況時，可以拿出來用的道具」，使用條件設成 `meet_1`（遇到阿壹），
   用下去會唱歌、偷走對方一根螃蟹腳、把你送回家，而你一枚心幣都沒交出去。
   作者在 v11 寫「我去玩一次棒球了，不愧是我們的鴨子道具，好玩」。
2. **「粗糙的地方」整段重寫。**她在 v1 就寫明「一堆陷阱劇情，都有可以避免的方法～
   看玩家有沒有突然想到了」「笑容快壓不下去了」「沒看攻略我也會走錯路」，
   v20 還在問「大家相信誰啊？有沒有被我誤導」。陷阱是設計，不是沒修乾淨。
3. **日記是後來補的番外。**作者在 v22 寫「更新一個小番外，把一些角色的相處方式寫出來給讀者看」。
4. 拿掉另外兩個編出來的時間（「四十分鐘」「幾十分鐘」）。
**2026-09-18（第三輪）**：作者說主線道具那段寫得正確，日記只有 4 月 20 日的解讀不對。她是對的。

1. **4 月 20 日讀反了方向。**原文是「阿道說我為什麼要和阿壹說<b>他</b>的壞話」，
   那個「他」是阿道自己。被講壞話的是阿道，被說成講話的人是泥巴人，中間經手的是阿壹。
   我原本寫成「泥巴人沒說過阿壹的壞話」，主詞受詞整個顛倒。
   作者後來把整條說完，共三點：

   - **這一則裡的每個「他」都是阿道**，包含最後那句「阿道說他不理我了」——是阿道不想再理泥巴人了。
   - **阿壹 4 月 10 日起不理泥巴人，是因為他正在一個一個去找別人亂說。**
     泥巴人那句辯解「我最近都沒看到阿壹啊」正好解釋了十天前的那一則。
   - **4 月 20 日的真相是：阿壹去跟阿道說泥巴人在講阿道的壞話。**
     阿道之所以會親自跑來問，是因為他前面對泥巴人很好（3 月 1 日送小餅乾的就是他），
     作者的原話是「一種我對你那麼好，你為什麼這樣對我的感覺」。

   頁面上因此多了三處：3 月 1 日加註記當伏筆、4 月 10 日與 4 月 20 日標上
   **「作者修訂」的粉紅標籤**（第 3 節開頭說明標籤的意思），
   第 4 節的「整件事的三段」與第 7 節新增一段〈作者自己講的四月二十日〉。
2. **順手修掉一個顯示 bug。**日期解析的天氣欄位貪到換行後面，
   沒寫天氣的十則日記（4/2、5/20、6/20、6/21、7/2、8/4、8/10、8/16、8/22、8/30）
   整句被吃進日期那一行的小字裡。改成天氣只認第一行的「X天」。

5. **密報的第二個取得點升級成主線資訊。**原本只寫在第 5 節末尾的警告框裡、框成「補救機制」。
   實際條件是市政府那條線要求 `DuckPaper == 0`，所以拿不到第二張、也不可能同時有兩張，
   一輪最多用兩次；道具說明的「只有一次機會」講的是一張撕一次。作者在 v19 特地抱怨過沒人去真相之門。
